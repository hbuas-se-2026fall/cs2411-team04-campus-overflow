# 开发者须知

> README 只保证「五分钟跑起来」。环境细节、测试基线、账号获取、排错全部放这里，按需查阅。
> 本文对应 Sprint 0 的 `PB-02`（开发者环境说明），原 `#13` 的 B 部分。

## 1. 环境版本

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| JDK | **21** | `java -version` 必须显示 21；17 编译会失败 |
| Maven | 3.9+ | 用仓库自带的 wrapper 也行 |
| Node.js | **20 或 22（LTS）** | 不要用 24，Vite 5 可能有兼容问题 |
| MySQL | 8.0+ | 推荐用 `deploy/docker-compose.yml` 里的（已配 `ngram_token_size=2`，中文搜索依赖它） |
| Redis | 7+ | 排行榜与列表缓存用 |

## 2. 中间件与连接参数

```bash
# 推荐：用 compose 起 MySQL + Redis（端口、库名、账号密码都已配好）
docker compose -f deploy/docker-compose.yml up -d mysql redis
```

默认连接参数（可用环境变量覆盖，见 `backend/co-bootstrap/src/main/resources/application.yml`）：

| 变量 | 默认值 |
| --- | --- |
| `DB_HOST` / `DB_PORT` | `localhost` / `3306` |
| `DB_NAME` | `campus_overflow` |
| `DB_USER` / `DB_PASSWORD` | `campus` / `campus_dev_pwd` |
| `REDIS_HOST` / `REDIS_PORT` | `localhost` / `6379` |
| `SERVER_PORT` | `8080` |

不用 Docker 也可以，但**自建 MySQL 必须手动设置 `ngram_token_size=2`**，否则中文搜索查不出结果。

## 3. 哪些测试必须绿，哪些红是正常的

跑全量 `mvn test` 时**一定会有大量失败**，这不是环境坏了。判断标准是模块：

| 模块 | 状态 |
| --- | --- |
| `co-shared-kernel` | ✅ 必须全绿 |
| `co-identity/co-identity-domain` | ✅ 必须全绿 |
| `co-qa/co-qa-domain` | ✅ 必须全绿 |
| `co-qa/co-qa-application` 及之后 | ⬜ 大量 `UnsupportedOperationException`，属预期 |

**只跑「必须绿」的那三个模块**（这才是提交前的自检命令）：

```powershell
mvn --% -B test -pl co-shared-kernel,co-identity/co-identity-domain,co-qa/co-qa-domain -am
```

> ⚠️ **Windows PowerShell 5.1 的坑**：`-D` 参数里的 `.` 会被 PowerShell 拆断，必须加 `--%` 前缀，否则报
> `Unknown lifecycle phase ".failIfNoSpecifiedTests=false"`。用 Git Bash 或 PowerShell 7 则不需要。

## 4. 怎么拿到教师 / 管理员账号

三种方式，按推荐顺序。

### 方式一（最简单）：用 `demo` profile 的种子数据

```bash
mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=demo
```

启动后自动创建以下账号，**密码全部是 `Campus2026`**：

| 用户名 | 昵称 | 角色 |
| --- | --- | --- |
| `admin01` | 系统管理员 | 管理员 |
| `T2001` | 王老师 | 教师 |
| `TA3001` | 李助教 | 助教 |
| `2023001` / `2023002` / `2023003` | 小明 / 小红 / 小刚 | 学生 |

> ⚠️ `demo` profile 会调用尚未实现的业务代码，**当前会启动失败**。等 Q&A 应用层（批次 2）做完后才能用。
> 在那之前请用方式二或三。

### 方式二：注册后直接在数据库里改角色

先正常注册一个账号，然后：

```sql
-- 提升为教师
UPDATE id_user SET role = 'TEACHER' WHERE username = '你的学号';
-- 提升为管理员
UPDATE id_user SET role = 'ADMIN'   WHERE username = '你的学号';
```

角色取值：`STUDENT` / `TA` / `TEACHER` / `ADMIN`。

> 注意：`id_user.role` 是**全局角色**。课程内的角色（这门课的老师/助教）由 `id_course_member.role` 表达，
> 两者不是一回事——课程内的教师权限来自课程成员关系，不是全局角色。

### 方式三：用管理员账号调用接口

```bash
POST /api/v1/admin/users                      # 创建教职工账号（body 里指定 role）
PUT  /api/v1/admin/users/{userId}/role        # 修改已有用户的全局角色
POST /api/v1/admin/users/{userId}/verify      # 认证校园身份（显示认证徽章）
```

详见 `http://localhost:8080/swagger-ui.html` 的 Admin 分组。

## 5. 常见报错

| 报错 | 原因与处理 |
| --- | --- |
| `UnsupportedOperationException: TODO(S2)...` | 正常，这个方法还没实现。看 `docs/status.md` 当前批次 |
| `mvn test` 大量失败 | 正常，见第 3 节。只有三个模块必须绿 |
| `Unknown lifecycle phase ".failIfNoSpecifiedTests=false"` | PowerShell 5.1 拆断了 `-D` 参数，加 `--%` 前缀 |
| `No tests matching pattern "XxxTest"` | 用了 `-am` 时依赖模块也会按 `-Dtest` 过滤，加 `-Dsurefire.failIfNoSpecifiedTests=false` |
| 后端起不来，报 Flyway 校验失败 | 本机 MySQL 版本或时区不对，改用 compose 里的 MySQL |
| `Connection refused` 连不上 GitHub | 全局 git 代理没关，见 `docs/git代理切换.md` |
| `.ps1` 脚本报中文乱码 / 解析错误 | PowerShell 5.1 需要 UTF-8 **BOM**，用记事本另存为「UTF-8 带 BOM」 |
| `Unsupported character encoding 'utf8mb4'`（SQL State S1009） | JDBC URL 的 `characterEncoding` 写成了 `utf8mb4`，而 Java 只认 `UTF-8`（服务端仍可用 utf8mb4，驱动会自动映射）。`application.yml:8` 已改为 `UTF-8`；本地起 jar 时不必再用 `--spring.datasource.url=` 手动覆盖 |

## 6. Docker 环境

本项目用 Docker 跑 MySQL / Redis / 后端 / 前端。**完整基线数据见 [`docs/reports/docker-baseline.md`](reports/docker-baseline.md)**，本节只讲怎么装、怎么用、怎么排错。

### 6.1 装什么

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| Docker Desktop | 4.100.0（实测） | 必须用 Desktop，不能只在 WSL 里装 docker engine（`#76` 要求记录版本号） |
| WSL2 | 3.0.1.0 / 内核 6.18.40.1-1 | Docker Desktop 的运行时后端 |

Docker Desktop 没有中文界面，官方也不提供语言包。

### 6.2 安装步骤

```powershell
# 1. 装 WSL2（必须重启）
wsl --install --no-distribution

# 2. 重启后验证
wsl --status          # 应显示「默认版本: 2」

# 3. 装 Docker Desktop
winget install --id Docker.DockerDesktop --source winget `
  --accept-source-agreements --accept-package-agreements

# 4. 首次启动点「Skip」跳过登录，左下角出现 Engine running 即就绪

# 5. 验证
docker run --rm hello-world
```

### 6.3 必须做的一步：把磁盘镜像搬出 C 盘

WSL2 的磁盘镜像默认在 `C:\Users\<用户>\AppData\Local\Docker\wsl\`，会随镜像增长到 5–20 GB。

**Docker Desktop → Settings → VM resources → Disk image location → `D:\DockerData\DockerDesktopWSL` → Apply & restart**

（4.100.0 里这页叫 `VM resources`，旧版本叫 `Resources`。）

程序本体 `C:\Program Files\Docker` 占 3.91 GB，这块搬不了。

### 6.4 本机已装 MySQL 的必须处理

如果本机装了 MySQL 服务且是开机自启，会抢占 3306，导致 `co-mysql` 起不来：

```
Error response from daemon: Ports are not available: exposing port TCP 0.0.0.0:3306
-> 0.0.0.0:0: listen tcp 0.0.0.0:3306: bind: Only one usage of each socket address
```

改成手动启动（**在 cmd 里执行，cmd 没有 `Set-Service` 这个 cmdlet**）：

```cmd
sc config MySQL start= demand
```

`start=` 后面**必须有空格**，这是 `sc` 的语法要求。验证：`sc qc MySQL` 应显示 `START_TYPE : 3 DEMAND_START`。

### 6.5 常用命令

```powershell
# 起中间件（日常开发够用）
docker compose -f deploy/docker-compose.yml up -d mysql redis

# 起全部（含后端 8080 与前端 80）
docker compose -f deploy/docker-compose.yml up -d --build

# 看状态
docker compose -f deploy/docker-compose.yml ps

# 看日志
docker compose -f deploy/docker-compose.yml logs -f backend

# 清库重建（答辩前必做，见 6.7）
docker compose -f deploy/docker-compose.yml down -v
```

### 6.6 一键自检

```powershell
.\http\docker-check.ps1            # 全量 12 项
.\http\docker-check.ps1 -SkipApp   # 只查中间件
```

全过时 `exit 0`。脚本会自动补 `C:\Program Files\Docker\Docker\resources\bin` 进 `PATH`，
所以装 Docker 之前打开的终端也能直接跑。

### 6.7 清库重建（答辩前必做）

`DemoDataSeeder` 第一行是 `if (identity.findByDisplayName("系统管理员").isPresent()) return;`，
**库里已有数据就直接跳过**。所以历史用户不会补建声誉账户，教师账号拿不到 1000 悬赏积分，
答辩演示「发起悬赏」会失败。

```powershell
docker compose -f deploy/docker-compose.yml down -v
docker compose -f deploy/docker-compose.yml up -d
```

### 6.8 Docker 相关报错

| 报错 | 原因与处理 |
| --- | --- |
| `docker: command not found` | 终端是在装 Docker 之前打开的。新开一个窗口，或 `$env:PATH = "C:\Program Files\Docker\Docker\resources\bin;$env:PATH"` |
| `failed to connect to the docker API at npipe://...` | Docker Desktop 没启动。`Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"`，约 5 秒就绪 |
| `error getting credentials - err: exec: "docker-credential-desktop"` | 同上，`PATH` 里缺 `resources\bin` |
| `failed to fetch anonymous token: ... dial tcp [2a03:...]:443` | Docker Hub 的 IPv6 不通。**先单独 `docker pull <镜像名>` 预拉，再 `build`** |
| `Ports are not available: ... 3306` | 本机 MySQL 抢了端口，见 6.4 |
| `Unable to access jarfile app.jar` | `#80` 之前的旧问题，`develop` 上已修 |
| `using a password on the command line interface can be insecure` 混进查询结果 | 别用 `mysql -p密码`，改用 `docker exec -e MYSQL_PWD=密码 co-mysql mysql -u用户` |
| `Invoke-WebRequest` 拿到乱码 / 中文字节数组 | PS 5.1 的 `.Content` 是 `Byte[]`，用 `[Text.Encoding]::UTF8.GetString($r.Content)` 解码 |
| 发中文 JSON 报 `422 QA-1004 ... ????` | PS 5.1 按 GBK 编码了。用 `-Body ([Text.Encoding]::UTF8.GetBytes($json))` 并设 `-ContentType 'application/json; charset=utf-8'` |
