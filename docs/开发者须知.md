# 开发者须知

> README 只保证「五分钟跑起来」。环境细节、测试基线、账号获取、排错全部放这里，按需查阅。
> 本文对应 Sprint 0 的 `PB-02`（开发者环境说明），原 `#13` 的 B 部分。

## 1. 环境版本

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| JDK | **21** | `java -version` 必须显示 21；17 编译会失败 |
| Maven | 3.9+ | 用仓库自带的 wrapper 也行 |
| Node.js | **20 或 22（LTS）** | 不要用 24，Vite 5 可能有兼容问题 |
| MySQL | 8.0+ | 推荐用 `deploy/docker-compose.yml` 里的（已配 `ngram_token_size=2`，中文搜索依赖它） |
| Redis | 7+ | 排行榜与列表缓存用 |

## 2. 中间件与连接参数

```bash
# 推荐：用 compose 起 MySQL + Redis（端口、库名、账号密码都已配好）
docker compose -f deploy/docker-compose.yml up -d mysql redis
```

默认连接参数（可用环境变量覆盖，见 `backend/co-bootstrap/src/main/resources/application.yml`）：

| 变量 | 默认值 |
| --- | --- |
| `DB_HOST` / `DB_PORT` | `localhost` / `3306` |
| `DB_NAME` | `campus_overflow` |
| `DB_USER` / `DB_PASSWORD` | `campus` / `campus_dev_pwd` |
| `REDIS_HOST` / `REDIS_PORT` | `localhost` / `6379` |
| `SERVER_PORT` | `8080` |

不用 Docker 也可以，但**自建 MySQL 必须手动设置 `ngram_token_size=2`**，否则中文搜索查不出结果。

## 3. 哪些测试必须绿，哪些红是正常的

跑全量 `mvn test` 时**一定会有大量失败**，这不是环境坏了。判断标准是模块：

| 模块 | 状态 |
| --- | --- |
| `co-shared-kernel` | ✅ 必须全绿 |
| `co-identity/co-identity-domain` | ✅ 必须全绿 |
| `co-qa/co-qa-domain` | ✅ 必须全绿 |
| `co-qa/co-qa-application` 及之后 | ⬜ 大量 `UnsupportedOperationException`，属预期 |

**只跑「必须绿」的那三个模块**（这才是提交前的自检命令）：

```powershell
mvn --% -B test -pl co-shared-kernel,co-identity/co-identity-domain,co-qa/co-qa-domain -am
```

> ⚠️ **Windows PowerShell 5.1 的坑**：`-D` 参数里的 `.` 会被 PowerShell 拆断，必须加 `--%` 前缀，否则报
> `Unknown lifecycle phase ".failIfNoSpecifiedTests=false"`。用 Git Bash 或 PowerShell 7 则不需要。

## 4. 怎么拿到教师 / 管理员账号

三种方式，按推荐顺序。

### 方式一（最简单）：用 `demo` profile 的种子数据

```bash
mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=demo
```

启动后自动创建以下账号，**密码全部是 `Campus2026`**：

| 用户名 | 昵称 | 角色 |
| --- | --- | --- |
| `admin01` | 系统管理员 | 管理员 |
| `T2001` | 王老师 | 教师 |
| `TA3001` | 李助教 | 助教 |
| `2023001` / `2023002` / `2023003` | 小明 / 小红 / 小刚 | 学生 |

> ⚠️ `demo` profile 会调用尚未实现的业务代码，**当前会启动失败**。等 Q&A 应用层（批次 2）做完后才能用。
> 在那之前请用方式二或三。

### 方式二：注册后直接在数据库里改角色

先正常注册一个账号，然后：

```sql
-- 提升为教师
UPDATE id_user SET role = 'TEACHER' WHERE username = '你的学号';
-- 提升为管理员
UPDATE id_user SET role = 'ADMIN'   WHERE username = '你的学号';
```

角色取值：`STUDENT` / `TA` / `TEACHER` / `ADMIN`。

> 注意：`id_user.role` 是**全局角色**。课程内的角色（这门课的老师/助教）由 `id_course_member.role` 表达，
> 两者不是一回事——课程内的教师权限来自课程成员关系，不是全局角色。

### 方式三：用管理员账号调用接口

```bash
POST /api/v1/admin/users                      # 创建教职工账号（body 里指定 role）
PUT  /api/v1/admin/users/{userId}/role        # 修改已有用户的全局角色
POST /api/v1/admin/users/{userId}/verify      # 认证校园身份（显示认证徽章）
```

详见 `http://localhost:8080/swagger-ui.html` 的 Admin 分组。

## 5. 常见报错

| 报错 | 原因与处理 |
| --- | --- |
| `UnsupportedOperationException: TODO(S2)...` | 正常，这个方法还没实现。看 `docs/status.md` 当前批次 |
| `mvn test` 大量失败 | 正常，见第 3 节。只有三个模块必须绿 |
| `Unknown lifecycle phase ".failIfNoSpecifiedTests=false"` | PowerShell 5.1 拆断了 `-D` 参数，加 `--%` 前缀 |
| `No tests matching pattern "XxxTest"` | 用了 `-am` 时依赖模块也会按 `-Dtest` 过滤，加 `-Dsurefire.failIfNoSpecifiedTests=false` |
| 后端起不来，报 Flyway 校验失败 | 本机 MySQL 版本或时区不对，改用 compose 里的 MySQL |
| `Connection refused` 连不上 GitHub | 全局 git 代理没关，见 `docs/git代理切换.md` |
| `.ps1` 脚本报中文乱码 / 解析错误 | PowerShell 5.1 需要 UTF-8 **BOM**，用记事本另存为「UTF-8 带 BOM」 |
