## 用户故事

作为团队，我们需要一个唯一的任务看板，以便不用在群里问"谁在做什么"。

## 验收标准

- [ ] GitHub Projects 建好，四列：`Ready` / `进行中` / `待评审` / `完成`
- [ ] Milestone 建好：`Sprint 1`（后续 `Sprint 2`…`Sprint 4` 按需）
- [ ] 批次 1 的 10 张 Issue 已进入看板 `Ready` 列
- [ ] 每张卡都填了负责人（Assignee）

## 实现落点

- 网页：仓库 → Projects → New project → Board
- 网页：Issues → Milestones → New milestone

## 完成定义

- [ ] 看板截图发到群里
- [ ] `docs/status.md` 中记录看板链接
- [ ] 已更新本人 `docs/progress/<用户名>.md`
