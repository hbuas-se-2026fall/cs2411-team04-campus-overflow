## 用户故事

作为用户，我希望对他人内容投票、改投或撤销，也能评论与一层回复，以便评价和追问。

## 验收标准

- [ ] `VoteAndCommentTest` 全绿
- [ ] 给自己投票 → 422 `QA-1015`，异常消息必须包含"自己"
- [ ] 投票值不是 -1 / 0 / +1 → `QA-1014`
- [ ] `change()` 返回旧值，并更新 `updatedAt`
- [ ] 评论正文 2–600 字符，越界 → `QA-1003`
- [ ] 回复的父评论不是顶层 → `QA-1016`
- [ ] 回复的 targetType / targetId 与父评论不一致 → `QA-1017`
